0. 원커맨드 자동 설치 (가장 빠른 길)

macOS · Linux · WSL · Termux
curl -fsSL https://gitsong123.github.io/taegomap/agent-skill-dashboard/install.sh | bash
Windows PowerShell
irm https://gitsong123.github.io/taegomap/agent-skill-dashboard/install.ps1 | iex

스크립트가 recommended-mcp.json을 .mcp.json에 병합하고, claude CLI가 있으면 claude mcp add까지 실행합니다.

1. 저장소와 대시보드

저장소 gitsong123/taegomap · 라이브 Pages 대시보드
  • 대시보드는 agent-skill-dashboard/index.html로 배포되며, 이 페이지 자체가 카탈로그입니다.
  • 저장소를 받아 두면 프로젝트별 .mcp.json을 그 자리에서 만들 수 있습니다: git clone https://github.com/gitsong123/taegomap.git

2. Claude Code에 적용

  1. 위 claude mcp add 탭에서 명령을 복사합니다.
  2. 터미널에서 그대로 실행합니다. 프로젝트에만 적용하려면 프로젝트 폴더에서, 모든 프로젝트에 적용하려면 --scope user를 붙입니다.
  3. Claude Code를 다시 열고 /mcp를 입력해 서버가 connected인지 확인합니다.
  4. “방금 등록한 스킬로 이 기능을 구현해줘”처럼 도구 이름을 언급하면 인식이 빠릅니다.

3. Grok Bot에 적용

  1. Grok Bot 탭의 grok_skills.json을 복사합니다.
  2. 봇이 읽는 설정 위치(또는 .mcp.json을 읽는 경우 그 파일)에 붙여넣고 재시작합니다.
  3. 스킬 목록에 enabled: true로 표시되면 연결 완료입니다.

4. 토큰을 아끼며 쓰는 요령

  • 먼저 Context7로 정확한 API 스펙만 받고, 코드 탐색은 AST 심볼 리더로 좁힙니다.
  • 큰 저장소는 Repomix로 구조만 인덱싱하고, 리뷰는 Diff 인스펙터로 변경분만 봅니다.
  • 설계가 애매하면 Sequential Thinking으로 계획을 먼저 세워 재작업을 줄입니다.
JSON은 프로젝트 루트의 .mcp.json에 그대로 붙여넣으세요.
